# Synthetic demonstration output

`demo.png` and `demo_summary.json` were produced by:

```bash
python examples/synthetic.py --output runs/demo_20261015
```

One prespecified example seed (7) was executed; no seeds or outcomes were
selected for appearance. This is not a manuscript benchmark. The dark squares
indicate pairs of treatments in the same **estimated** group. The example
uses 240 training, 120 validation, and 400 test observations and four treatments.
The validation curve is a diagnostic, not a theoretical convergence guarantee.
